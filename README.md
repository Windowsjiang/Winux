## Winux Unix-Like OS
[Logo.jpeg](Logo.jpeg)
Winux is a Open-source OS built-on Windows Source and Linux Kernel.
Uses GNU glib compiler to compile the source.
Included Zip Tools and [VScode](code.visualstdio.com) , MD5, SHA veriers.
<kbd> ~/home </kbd> folder uses Windows Filesystem format.
Lastest version is avaluable at [github.com/Windowsjiang/Winux/releases](github.com/Windowsjiang/Winux/releases) and the website is at [here](windowsjiang.github.io/winux) (Comparing).

## Why I Devolop it
In the past, file on Linux and Windows can't execute on eachother(e.g. *.sh can't execute on Windows and *.bat can't execute on Linux either).
And Windows and Linux switch to eachother needs complicated way.Windows's beautiful theame cannnot run on Linux.

As fixing theese problem, Winux Borns.
- Included all the devolop tools
- Install easy
- Souces download easyly
